Companion to Parallel Policy-Gradient Methods for Parameter Optimization of Nonlinear Feedback Controllers. Each policy-gradient iteration first evaluates the closed-loop state trajectory in parallel. This demo shows how a Gauss–Newton (DEER) solver turns a guessed trajectory into the true one, one update at a time.

Enter the two right-hand sides. Use x1, x2, dt, rho, pi, e; + − * / ^ and parentheses. Functions: sin, cos, tan, tanh, exp, log, sqrt, atan, sinh, cosh, pow. Multiplication needs *.

The map is checked at e. Initialization around equilibrium uses this point; if it is not a fixed point, it is labeled as a reference instead.

L(ξ) = ½ Σₖ₌₁ᴺ ‖rₖ‖², where rₖ = ξₖ − FΔt(ξₖ₋₁) and ξ₀ = x₀.

The learning rate η is an optimization parameter; Δt is the physical time step. Gradient descent uses all residuals from the current guess and updates every free point simultaneously. For k = N, the next-residual term is zero.

Fh(x) = ρʰ R(0.4h + b(h)‖x‖²)x, h = Δt

b(h) = 0.18 (ρ²ʰ − 1)/(ρ² − 1); when ρ = 1, b(h) = 0.18h.

R is a planar rotation. This family is consistent across time steps: Fh ∘ Fs = Fh+s. At Δt = 1 it recovers the original example. The displayed one-unit spectral radius is ρ(DF₁(0)) = ρ; the actual per-step radius is ρ(DFΔt(0)) = ρ^Δt. Away from equilibrium, the Jacobian's spectral radius can differ.

For this built-in model, ρ < 1 gives global exponential stability of the physical system. This alone does not guarantee solver convergence.

Custom discrete equations define FΔt directly; include dt wherever the map needs it. Custom ODE equations define dx/dt = f(x), and the app uses FΔt(x) = x + Δt f(x) (forward Euler). The Jacobian is obtained by differentiating the entered expressions. Numerical stability depends on the equations and Δt; no global stability is assumed.

The clipped method rescales the full Jacobian by min(1, a/‖DFΔt‖F). State values are not clipped. The reference trajectory, updates, loss, and error use all N time steps; only the drawing is sampled when N is large. The exact selected time index is always included. Lines between displayed samples may skip time steps.

Calculations run in a background worker. Only the current pair of guesses and two checkpoints are retained, so moving backward may require recomputation. Large horizons with many solver iterations can take time; use Stop to cancel. The iteration slider computes when you release it.

The true trajectory is shown as a reference; it is not used to compute solver updates. Gaussian spread σ is the standard deviation in each coordinate. The interpolation preset has mean (1 − k/N)x₀ + (k/N)e. N controls the horizon, and the physical duration is NΔt. The reported loss is a sum, not an average over time.
